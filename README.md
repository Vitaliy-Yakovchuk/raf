# raf

TypeScript-утиліта автоматизації агентної розробки Orchestrator. Початковий інкремент: CLI-каталог, help і бібліотека SQLite; запуск агентів та служба ще не реалізовані.

Перевірене середовище — Node 25.4.0; зовнішніх runtime-залежностей немає. SQLite використовує вбудований node:sqlite.

- `npm run build` — скомпілювати JSON-каталог із `../conf` у `dist/catalog.json`.
- `node bin/raf.ts help agent run` — переглянути довідку.
- `src/` — каталог, CLI, збірка й бібліотека стану.
- `test/` — адресні групи: `test:cli`, `test:cli:qa`, `test:bootstrap`, `test:state`. Запускати потрібну групу із зовнішнім таймаутом 1200 с.

Операційні команди повертають COMMAND_UNAVAILABLE, доки їхні обробники не реалізовані. Робоча SQLite не відкривається для help; бібліотека сховища потребує явно заданого шляху. Стан реалізації — у tasks.md відповідних змін `../openspec/changes`.
