## Реалізація та самоперевірка читабельності

src/test-runs.ts: reconcileLegacyPlaywrightIds та виклик у integration-гілці runTestRun. Helper має одну відповідальність: для ledger ID з точним префіксом ` > <file> > ` знайти зібрану канонічну пару file/name. Явний guard залишає інші ID незмінними; Map забезпечує точне зіставлення; повертається копія агрегату з оновленими knownRed/unexecuted/unknown, без зміни вихідного стану. Поля історії й timeoutCount зберігаються. Виклик обмежений integration + node-test-events; Vitest і unit не змінюються. Немає нових валідацій, таймаутів або лімітів. Непідтверджені IDs не вилучаються і не стають passed.

Переглянуто всю змінену функцію runTestRun у межах внесеного потоку та новий helper: canonicalize явно отримує списки, повертає списки; запис стану лишається в наявній транзакції. Назви відображають роль, вкладеність helper мінімальна, побічних ефектів немає.
