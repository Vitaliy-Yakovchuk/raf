# Стадія context-review

Проаналізуй стартовий контекст запусків з пакета `context-review.due`, названого в дорученні (ID пакета й runId). Процедура — скіл `skills/dev-start-tokens/SKILL.md`; вимоги — startup-context-review «Аналіз стартового контексту агентів» і «Оптимізація в брифі й репозиторії».

Знахідки оформлюй в OpenSpec за чинним flow, не дублюй наявних змін. Правки поза межами запису передай main точним патчем. Передай результат у JSON за шляхом і схемою доручення: ID пакета, досліджені runId, «знайдене → дія → адреса зміни».
