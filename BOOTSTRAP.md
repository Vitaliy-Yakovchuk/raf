# Перший інкремент raf

Node 25 виконує TypeScript без runtime-залежностей. `npm run build` читає каталоги з `../conf` відносно raf-develop і атомарно записує `dist/catalog.json`. Помилка компіляції зберігає попередній артефакт. Після зміни conf потрібна повторна збірка.

`node bin/raf.ts help` читає лише скомпільований артефакт. Без артефакту CLI повертає структуровану помилку з порадою виконати збірку; не запускає її самостійно.

Реалізовано компіляцію каталогу, довідку й перевірку описаних параметрів. Усі операційні команди наразі мають явні недоступні обробники: після перевірки аргументів повертають COMMAND_UNAVAILABLE та ненульовий код. Наявність команди у довідці не означає завершення її функціональності. Довідка не виконує операцій, не запускає зовнішні CLI й не відкриває SQLite. Зокрема runner limits не збирає і не вигадує квоти.
