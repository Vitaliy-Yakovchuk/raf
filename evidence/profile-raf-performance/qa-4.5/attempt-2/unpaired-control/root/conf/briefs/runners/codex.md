# Runner codex

Ця частина призначена для CLI `codex`, запущеного raf через tmux. Модель і effort уже обрані raf; не замінюй їх самостійно. Використовуй доступні інструменти цього CLI для дорученої роботи. Підсумкова відповідь у чаті не замінює JSON за `report_path` і `report_schema` з доручення. Формат запуску, доставки й продовження визначає адаптер CLI, а не текст цього брифа.
